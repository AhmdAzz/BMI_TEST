# Kalkulator BMI (Body Mass Index)

Aplikasi Kalkulator BMI sederhana untuk mengecek berat badan ideal berdasarkan tinggi badan dan jenis kelamin.

## Fitur
* Pemilihan jenis kelamin (Pria / Wanita).
* Input parameter metrik untuk tinggi dan berat badan.
* Perhitungan otomatis untuk skor BMI, kategori kesehatan, dan target berat badan ideal.

## Cara Penggunaan
1. Jalankan aplikasi Kalkulator BMI.
2. Pada halaman utama, pilih jenis kelamin dengan mengklik tombol **Pria** atau **Wanita**[cite: 2].
3. Masukkan tinggi badan pada kolom **Tinggi Badan(cm)** (contoh: 165)[cite: 2].
4. Masukkan berat badan pada kolom **Berat Badan(kg)** (contoh: 65)[cite: 2].
5. Klik tombol **CEK**[cite: 2].
6. Layar akan beralih ke halaman **BMI TEST RESULT**[cite: 3].
7. Pada halaman hasil, kamu bisa melihat **BMI SCORE** (contoh: 23,88), **Kategori** (contoh: Normal), dan **Berat Ideal**[cite: 3].
